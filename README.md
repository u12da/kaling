# 카링 실 게이지

**사이트: https://u12da.github.io/kaling/**

메이플스토리 카링 1·2·3페이즈에서 실과 흉수에게 맞을 때 궁기·도올·혼돈 게이지가 어떻게 바뀌는지 보여주는 한 장짜리 웹페이지예요. 설치할 것 없이 `index.html`을 브라우저로 열면 돼요. 휴대폰(아이폰 17 프로 기준)에서는 위쪽을 줄이고 게이지와 전투 화면이 한 화면에 같이 보이게 바뀌어요.

## 쓰는 법

1. 위에서 난이도를 고르고, 지금 있는 방(1페 궁기·혼돈·도올의 방, 2페, 3페)을 눌러요.
2. 맞은 실이나 흉수를 전투 화면이나 오른쪽 목록에서 눌러요. 인게임처럼 생긴 둥근 삼각형 게이지(위 혼돈, 오른쪽 아래 궁기, 왼쪽 아래 도올, 시계방향)가 바로 바뀌고 기록이 쌓여요.
   - X자로 겹친 실에 맞았으면 `X자 ×2`를 눌러요.
   - 키보드: 숫자키는 맞음, Shift+숫자키는 X자 ×2, Z는 되돌리기.
3. 목록의 `추천 / 무난 / 아슬아슬 / 터짐!` 표시는 그걸 맞았을 때 게이지가 500 쪽으로 돌아오는지, 터지는지 알려줘요.
4. 게이지 아래 **추천 순서**가 지금 화면에서 몇 대를 어떤 순서로 맞으면 균형이 맞는지 알려줘요. 터질 위험이 있는 건 **피할 것**으로 따로 떠요.
5. **목표**를 도터빌·혼터빌·궁터빌로 바꾸면 그 터빌 순서와 추천이 나와요 (보통 3페이즈).
6. **▶ 실전 연습**: 흉수는 계속 서 있고 실과 흉수 공격이 시간마다 내려와요. ←/→ 키나 화면을 눌러 움직이면서 피하거나 일부러 맞아서 60초 동안 게이지를 맞춰 보세요.
7. 게이지는 파티가 같이 써요. 게임 화면 숫자와 어긋나면 게이지 숫자를 눌러 바로 고쳐요. 두 칸만 넣고 `나머지 자동`을 누르면 합 1500으로 채워요.
8. 아래 **연습 문제**에서 실 색, 게이지 색, 방마다 실 위치, 지금 뭘 맞아야 하는지를 문제로 풀어 볼 수 있어요.
9. 휴대폰에서는 실을 길게 누르면 X자 ×2, `화면 켜두기`로 화면이 꺼지지 않게 할 수 있어요. 사파리 공유 → 홈 화면에 추가하면 앱처럼 열리고, 한 번 연 뒤에는 인터넷 없이도 돼요.

## 실제 배경 넣기

기본 배경은 계절(봄 궁기, 여름 도올, 가을 혼돈)을 그린 그림이에요. 실제 게임 배경으로 바꾸는 방법은 두 가지예요.

- **페이지에서 바로**: 전투 화면 아래 `실제 배경 넣기`를 누르거나, 스크린샷을 전투 화면에 끌어다 놓아요. 그 방에만 적용되고 이 브라우저에만 저장돼요.
- **폴더에 넣기**: `bg/` 폴더에 아래 이름으로 이미지를 넣으면 자동으로 써요 (`.webp`, `.jpg`, `.png`).

| 장소 | 파일 이름 |
| --- | --- |
| 1페이즈 궁기의 방 | `bg/p1-gungi.jpg` |
| 1페이즈 혼돈의 방 | `bg/p1-hondon.jpg` |
| 1페이즈 도올의 방 | `bg/p1-doul.jpg` |
| 2페이즈 | `bg/p2.jpg` |
| 3페이즈 | `bg/p3.jpg` |

실과 흉수 표시는 화면 비율(왼쪽·가운데·오른쪽)로 얹혀요. 맵 전체가 나오게 찍은 스크린샷일수록 잘 맞아요.

## 규칙 요약

| 맞은 것 | 오르는 게이지 | 내려가는 게이지 |
| --- | --- | --- |
| 빨간 실(매화) / 궁기 공격 | 궁기 (노란 게이지) | 혼돈 |
| 초록 실(난초) / 도올 공격 | 도올 (파란 게이지) | 궁기 |
| 노란 실(국화) / 혼돈 공격 | 혼돈 (보라 게이지) | 도올 |

- 게이지는 0~1000, 시작은 셋 다 500. 0이나 1000에 닿으면 터지고 정신력 −350, 터진 게이지는 더 이상 안 변해요.
- 1회 증감량(이지/노멀/하드/익스트림): 1페 55/60/70/85, 2페 100/110/110/150, 3페 65/70/90/110. X자 겹친 실은 2배.

수치와 배치는 나무위키·인벤·아카라이브 커뮤니티 공략 기준이고, 흉수 공격은 실과 같은 양으로 계산해요. 패치로 바뀌면 페이지의 `1회 증감량` 칸에서 고치면 돼요. 비공식 팬 도구이며 넥슨과 관계없어요.
